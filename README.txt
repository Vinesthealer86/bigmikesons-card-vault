BIGMIKE&SONS CARD VAULT — VERSION 1 STARTER

Included working features:
- Manual card entry for Pokémon, One Piece, MTG, Yu-Gi-Oh!, sports and other TCGs.
- Raw or graded records, including PSA, Beckett/BGS, CGC, SGC, TAG and listed Australian grading companies.
- Quantity, set, card number, condition, grade, notes, card photo, purchase cost and manually entered market value.
- Collection dashboard with total value, quantity and profit/loss.
- Search and category/status filters.
- Deck creation and selecting cards from your owned inventory.
- Front/back photo capture inputs.
- Guided manual condition checklist with a rough grade range.
- Black-and-gold mobile layout and installable PWA files.

Important limitations:
- This is a V1 prototype, not a finished commercial production app.
- Data is stored in this browser/device using localStorage. There is no account login, cloud sync or automatic backup yet. Clearing browser data can erase records.
- Photo scanning does not yet identify cards automatically.
- The grade checker is a manual checklist, not an AI vision model and not an official grade.
- Market prices are manually entered. No live marketplace connection or daily scheduled refresh is active.
- Daily pricing requires provider approval/licences, API credentials, a secure backend/database and scheduled server jobs. Do not put API secrets in browser code.
- TCGplayer access may be restricted; eBay sold-data API access may require approval; PriceCharting commercial access and coverage must be confirmed.

Install on iPhone:
1. Upload all files in this ZIP to a GitHub repository.
2. In GitHub, open Settings > Pages.
3. Select deploy from branch, choose main and /(root), then Save.
4. Wait for GitHub Pages to publish the site.
5. Open the published HTTPS website in Safari on iPhone.
6. Tap Share > Add to Home Screen > Add.

Before relying on it for valuable inventory, add cloud backup and test exports. Those are production-stage features, not included in this local prototype.
